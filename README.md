## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Joshpanamera/devops-portfolio.git
```

Navigate into the project:

```bash
cd devops-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
